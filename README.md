# File Peek

File Peek is a desktop utility for exploring files and directories.

It can scan directories and display their contents as a readable tree structure, similar to the directory structures commonly used in documentation and AI conversations. It can also take a supported tree structure and create the corresponding folders and files on the computer.

File Peek also provides built-in previews for many common file types, allowing files to be viewed or played without opening another application.

## Directory Trees

File Peek can scan an existing directory and turn it into a tree structure.

For example:

```text
my_project/
├── lib/
│   ├── main.dart
│   ├── core/
│   │   └── services/
│   │       └── storage.dart
│   ├── features/
│   │   └── settings/
│   │       └── settings_screen.dart
├── assets/
│   └── images/
│       └── logo.png
└── pubspec.yaml
```

The generated tree can be copied and shared as text.

File Peek can also work in reverse. A supported tree structure can be used to create the folders and files represented by it.

```text
Directory → Tree structure

Tree structure → Directory
```

## File Previews

File Peek supports a range of commonly used file types.

### Audio

Play popular audio formats such as **MP3, WAV, FLAC, OGG**, and more.

### Video

Play popular video formats such as **MP4, MKV, MOV, WebM**, and more.

### Images

View popular image formats such as **PNG, JPEG, GIF, WebP**, and more.

### Documents

View **PDF** documents, including documents containing text, images, graphics, and multiple pages.

### Spreadsheets

Work with popular spreadsheet formats such as **XLSX, XLS, CSV, ODS**, and more.

### Archives

Support for popular archive formats such as **ZIP, TAR, 7Z, RAR**, and more.

### Code

Preview files written in popular programming languages such as **Dart, Python, JavaScript, C++**, and more.
